# Candlepath

A Bloons TD 6-style tower defense game in which the towers are temporary candles that light the
enemies' path in the dark until they eventually burn out. The game design and project documentation
(written in Lithuanian) describe the mechanics, interface and art style.

- Engine: Unity 6000.3 LTS, "Universal 2D" template, 2.5D format
- `git lfs` is used to store large files (graphics, models, audio)

## Project structure

| Directory | Purpose |
|---|---|
| `Assets/` | Unity content (scenes, settings, sprites) |
| `Assets/Sprites/` | Generated sprites (see below) |
| `Assets/Environment/` | Floor/path tiles, Rusys map background and path waypoints (see below) |
| `Assets/Blender/` | `candlepath_sprites.blend`, the Blender scene the sprites are rendered from |
| `Art/Blender/` | Blender scripts that generate the sprites and the environment (outside `Assets/` so Unity does not import them) |
| `Art/Source/polyhaven/` | CC0 source textures used for the environment (with attribution) |

### Animations

`generate_sprites.py` can also render looping frame sequences (`-- Assets/Sprites [name-prefix ...] --anim`).
Every sprite except the wax puddle gets 8 frames in `Assets/Sprites/Anim/<sprite>/<sprite>_00..07.png`
(256x256, same camera and scale as the stills):

| Sprites | Motion |
|---|---|
| All candles, lanterns, Eternal Lamp | Flame flicker and sway |
| `candle_spark_*` | Sparks rise, drift and fade |
| `enemy_shadow` | Breathing pulse, blink on the last frame |
| `enemy_moth` | Wing flap and hover bob |
| `enemy_wind_spirit` | Hover bob, wave running along the tail |
| `enemy_wax_gnawer` | Waddle and tail wag |
| `enemy_golem` | Stomp, arm swing, pulsing cracks |
| `enemy_boss` | Looming pulse, hover, swaying hem, blink |

Loop: 8 frames at 10 fps. In Unity, run **Candlepath > Wire Sprite Animations** (`Assets/Editor/WireSpriteAnimations.cs`):
it imports the frames as sprites and adds a `SpriteFrameAnimator` to the tower and enemy prefabs, creating the
missing prefabs (`Assets/Prefabs/Towers/`, `Assets/Prefabs/Enemies/`) from the tea candle / `Enemy_Shadow` prefabs.
Towers switch animation per burn stage through `FlickerLight.frameAnimator`. Safe to run again.

Properties:

- 256x256 px, RGBA, orthographic camera at 60° elevation above the ground
- All sprites share the same scale, about 107 px per world unit, so use the same Pixels Per Unit
  for all of them in Unity
- Colors come from the main palette (design document, fig. 8): wax `#EFE3C2`, flame `#FF9A3C`,
  brass `#C8A25A`, stone `#2E2B3A`, shadows `#4A2F6B`
- The light glow, flame flicker, enemy "pulsing" and wax shrinking are **not** baked into the
  sprites; the game handles them (lighting and shader systems)

### Regenerating the sprites

Requires Blender 5.x. From the project root:

```bash
blender -b -P Art/Blender/generate_sprites.py -- Assets/Sprites
```

The script creates a separate scene named `Candlepath_Sprites` and overwrites `Assets/Sprites/*.png`.
To change the resolution, camera or models, edit `Art/Blender/generate_sprites.py`
(`RES`, `ORTHO`, `ELEV` and the `tea_candle` / `lantern` / `eternal_lamp` / ... functions).

## Environment (PoC, Rusys map)

Generated by `Art/Blender/generate_environment.py`: two CC0 [Poly Haven](https://polyhaven.com) textures
(Rock Tile Floor, Stone Floor; attribution in `Art/Source/polyhaven/README.md`) graded into the game
palette, then assembled into a winding-path map.

| File | Description |
|---|---|
| `rusys_background.png` | 1920x1080 map background: dark cellar floor and a winding path with a soft edge shadow |
| `rusys_path.json` | Path as a 16x9 grid (120 px cells): corner cells, pixel waypoints, path cells, enemy start and Eternal Lamp cell |
| `floor_cellar.png` | Seamless 512x512 dark flagstone floor tile |
| `path_stone.png` | Seamless 512x512 lighter cobblestone path tile |

The background is drawn at normal brightness: darkness and candle light are handled by the game. The path stays
inside columns 0-12 and rows 1-7, clear of the right tower panel and the top/bottom bars (design document, fig. 4).
`rusys_path.json` uses a top-left origin with y pointing down, so flip y for Unity.

Regenerate (Blender 5.x, from the project root):

```bash
blender -b -P Art/Blender/generate_environment.py -- Assets/Environment
```

To change the path, edit `PATH_CORNERS` in the script.

## Biblioteka and Koplyčia maps

`Assets/Maps/Map_2.unity` (Biblioteka: diagonal fork into two lanes) and `Map_3.unity` (Koplyčia: long corridor crossed by
two vertical corridors, five entrances) follow the map sketches in the design document (fig. 3 b). They are generated by
**Candlepath > Build Maps** (`Assets/Editor/MapBuilder.cs`), which copies Rusys (`Map_1`), repaints the tilemaps, rebuilds the
`PathNode` graph, places the Eternal Lamp and the static decorations, and creates the `MapDefinition`, `WaveSet`, catalog and
build-settings entries. The layouts, decoration positions and wave rules are at the top of that script; run the menu item again after editing.

Art for these maps (Poly Haven, CC0, fetched through the Blender MCP):

| Script | Output |
|---|---|
| `Art/Blender/generate_map_textures.py` | `Assets/Environment/floor_/path_` `library` and `chapel` tiles (`blender -b -P ... -- Assets/Environment`) |
| `Art/Blender/generate_decor.py` | `Assets/Decor/decor_*.png` props, rendered from the game camera. The models must be imported into the open Blender file first (list in the script header) |

Decorations block candle placement through `DecorBlocker` (`Assets/Scripts/DecorBlocker.cs`).

## Sandbox (editor only)

1. Run **Candlepath > Wire Sprite Animations** once (creates the tower and enemy prefabs).
2. Switch on **Candlepath > Sandbox Mode**, then press Play in a map scene (or start a map from the main menu).

`SandboxController` replaces `TowerBuilder` and `WaveSpawner` while active. Keys `1`-`5` select a tower, left click places it
(green/red ghost shows if the cell is free), right click removes it. `Q W E R T Y` spawn the six enemy types (count and
game speed are in the right-hand panel), `K` kills all enemies. Towers only burn down for now (no attack code yet), and
`WaveSpawner` logs a harmless "no map selected" error when started without a menu selection.
