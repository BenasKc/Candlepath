# Candlepath

A Bloons TD 6-style tower defense game in which the towers are temporary candles that light the
enemies' path in the dark until they eventually burn out. The game design and project documentation
(written in Lithuanian) describe the mechanics, interface and art style.

- Engine: Unity 6000.3 LTS, "Universal 2D" template, 2.5D format
- `git lfs` is used to store large files (graphics, models, audio)

## Project structure

| Directory | Purpose |
|---|---|
| `Assets/` | Unity content (scenes, settings, sprites) |
| `Assets/Sprites/` | Generated sprites (see below) |
| `Assets/Environment/` | Floor/path tiles, Rusys map background and path waypoints (see below) |
| `Assets/Blender/` | `candlepath_sprites.blend`, the Blender scene the sprites are rendered from |
| `Art/Blender/` | Blender scripts that generate the sprites and the environment (outside `Assets/` so Unity does not import them) |
| `Art/Source/polyhaven/` | CC0 source textures used for the environment (with attribution) |

## Sprites (PoC, milestone E2)

Sprites are modeled in Blender and rendered to PNG with a transparent background, from the same
camera angle as the game camera (design document, section 6.1).

| File | Description |
|---|---|
| `candle_tea_1_full`, `_2_mid`, `_3_low` | Tea candle (Arbatinė žvakelė), three wax-height stages |
| `lantern_1_full`, `_2_mid`, `_3_low` | Lantern (Žibintas), three wax-height stages |
| `eternal_lamp` | Eternal Lamp (Amžinoji lempa), the end of the path |
| `wax_puddle` | Wax puddle (Vaško likutis), left behind when a candle burns out |
| `enemy_shadow` | Shadow (Šešėlis) enemy base body with eyes |

Properties:

- 256x256 px, RGBA, orthographic camera at 60° elevation above the ground
- All sprites share the same scale, about 107 px per world unit, so use the same Pixels Per Unit
  for all of them in Unity
- Colors come from the main palette (design document, fig. 8): wax `#EFE3C2`, flame `#FF9A3C`,
  brass `#C8A25A`, stone `#2E2B3A`, shadows `#4A2F6B`
- The light glow, flame flicker, enemy "pulsing" and wax shrinking are **not** baked into the
  sprites; the game handles them (lighting and shader systems)

### Regenerating the sprites

Requires Blender 5.x. From the project root:

```bash
blender -b -P Art/Blender/generate_sprites.py -- Assets/Sprites
```

The script creates a separate scene named `Candlepath_Sprites` and overwrites `Assets/Sprites/*.png`.
To change the resolution, camera or models, edit `Art/Blender/generate_sprites.py`
(`RES`, `ORTHO`, `ELEV` and the `tea_candle` / `lantern` / `eternal_lamp` / ... functions).

## Environment (PoC, Rusys map)

Generated by `Art/Blender/generate_environment.py`: two CC0 [Poly Haven](https://polyhaven.com) textures
(Rock Tile Floor, Stone Floor; attribution in `Art/Source/polyhaven/README.md`) graded into the game
palette, then assembled into a winding-path map.

| File | Description |
|---|---|
| `rusys_background.png` | 1920x1080 map background: dark cellar floor and a winding path with a soft edge shadow |
| `rusys_path.json` | Path as a 16x9 grid (120 px cells): corner cells, pixel waypoints, path cells, enemy start and Eternal Lamp cell |
| `floor_cellar.png` | Seamless 512x512 dark flagstone floor tile |
| `path_stone.png` | Seamless 512x512 lighter cobblestone path tile |

The background is drawn at normal brightness: darkness and candle light are handled by the game. The path stays
inside columns 0-12 and rows 1-7, clear of the right tower panel and the top/bottom bars (design document, fig. 4).
`rusys_path.json` uses a top-left origin with y pointing down, so flip y for Unity.

Regenerate (Blender 5.x, from the project root):

```bash
blender -b -P Art/Blender/generate_environment.py -- Assets/Environment
```

To change the path, edit `PATH_CORNERS` in the script.
